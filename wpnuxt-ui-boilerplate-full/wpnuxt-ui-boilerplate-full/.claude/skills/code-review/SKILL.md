# Skill: Code Review

## Purpose

Review implementation against the boilerplate architecture and project
requirements.

## Review checklist

-   Correct layer and dependency direction.
-   No WordPress coupling in generic UI.
-   No unnecessary duplication.
-   Clear types and stable view models.
-   Loading/empty/error states handled.
-   Responsive behavior verified.
-   Accessibility preserved.
-   SEO implications checked.
-   Performance regressions considered.
-   Secrets/security boundaries preserved.
-   Tests/docs updated where required.
-   `CLAUDE.md` checklist matches actual state.

## Output

Report concrete issues with file/location, impact, and recommended fix.
Distinguish blockers from improvements.
