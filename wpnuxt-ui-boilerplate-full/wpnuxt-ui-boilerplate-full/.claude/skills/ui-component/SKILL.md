# UI Component Skill

When asked to create/refactor a component:
1. Read `CLAUDE.md` and `docs/ui-system.md`.
2. Classify it as UI primitive, section, or WordPress adapter.
3. Search for an existing component before adding a new one.
4. Define typed props/events first.
5. Keep raw WordPress data out of generic UI components.
6. Use semantic HTML and keyboard-safe interaction.
7. Use design tokens and mobile-first responsive behavior.
8. Add/update tests for non-trivial behavior.
9. Run typecheck/lint/tests relevant to the change.
10. Report changed files and any assumptions.
