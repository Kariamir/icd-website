# Skill: Forms

## Purpose

Implement reliable, accessible frontend forms and integrations.

## Procedure

1.  Confirm fields, validation, provider/backend, privacy, consent, and
    spam requirements.
2.  Use semantic labels and accessible error associations.
3.  Implement client validation for UX and server/provider validation
    for trust.
4.  Implement idle, pending, success, and failure states.
5.  Prevent accidental duplicate submissions.
6.  Add approved spam protection.
7.  Verify keyboard operation and error recovery.
8.  Document integration configuration.

## Rules

-   Never put provider secrets in client code.
-   Do not rely on placeholder text as the only label.
