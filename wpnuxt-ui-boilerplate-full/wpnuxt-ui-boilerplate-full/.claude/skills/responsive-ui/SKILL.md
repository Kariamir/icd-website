# Skill: Responsive UI

## Purpose

Make layouts robust across viewport sizes and real CMS content.

## Procedure

1.  Start from documented design behavior, not arbitrary breakpoints.
2.  Implement mobile, tablet, desktop, and wide-screen behavior as
    applicable.
3.  Test long headings, missing fields, different image ratios, long
    navigation, and localization.
4.  Prevent horizontal overflow.
5.  Keep touch targets usable.
6.  Verify typography, spacing, ordering, and media cropping at each
    supported range.

## Rules

-   Do not solve responsive problems with device-specific hacks when
    content/layout rules can solve them.
-   Do not assume Figma text lengths are production content lengths.
