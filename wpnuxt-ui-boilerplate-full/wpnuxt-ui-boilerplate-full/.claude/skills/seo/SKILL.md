# Skill: SEO

## Purpose

Implement technical SEO consistently for CMS-driven Nuxt pages.

## Procedure

1.  Read `docs/routing-seo.md`.
2.  Define title/meta mapping from WordPress or frontend defaults.
3.  Implement canonical URLs and Open Graph/social metadata.
4.  Implement structured data when content type warrants it.
5.  Configure sitemap, robots, indexing, and staging no-index behavior.
6.  Preserve heading hierarchy and crawlable internal links.
7.  Implement redirects for migrated URLs when required.
8.  Verify rendered production HTML metadata.

## Rules

-   Do not index preview/private/staging routes.
-   Avoid duplicate canonicals or conflicting metadata sources.
