# Skill: Design System

## Purpose

Create a consistent UI foundation reusable across pages and projects.

## Procedure

1.  Confirm brand/design inputs using the requirements-intake skill.
2.  Read `docs/ui-system.md`.
3.  Define semantic tokens for color, typography, spacing, sizing,
    radius, shadow, motion, and breakpoints.
4.  Define containers/grid and responsive conventions.
5.  Define interaction states: hover, focus, active, disabled, loading.
6.  Build primitives before repeating equivalent styles in sections.
7.  Keep tokens semantic rather than tied to one page.

## Rules

-   Do not hard-code repeated brand values throughout components.
-   Preserve accessibility in color, focus, typography, and motion
    choices.
