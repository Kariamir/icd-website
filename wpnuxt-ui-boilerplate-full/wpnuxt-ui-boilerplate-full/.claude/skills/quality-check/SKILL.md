# Quality Check Skill

Review, do not merely summarize.

1. Read `docs/definition-of-done.md`.
2. Inspect changed files and trace dependencies.
3. Check architecture boundaries and CMS coupling.
4. Check TypeScript quality and generated-type usage.
5. Check routing/404/SEO behavior.
6. Check responsive UI, semantic HTML, keyboard behavior, images, and loading/error states.
7. Check for duplicate/oversized WordPress queries and unnecessary client rendering.
8. Run available typecheck/lint/test/build commands.
9. Report findings by severity with exact file references.
10. Do not state that a check passed unless it was actually inspected or executed.
