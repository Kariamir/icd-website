# Page Implementation Skill

1. Read `CLAUDE.md`, `docs/architecture.md`, `docs/workflow.md`, and `docs/definition-of-done.md`.
2. Identify route, CMS fields, SEO requirements, and required page states.
3. Reuse existing sections/UI first.
4. Fetch via WPNuxt and map raw CMS data to view models.
5. Compose the page; do not place large CMS mapping logic in the template.
6. Add title/meta/canonical and correct 404 behavior.
7. Check mobile and desktop layouts.
8. Check keyboard/accessibility behavior.
9. Run typecheck, lint, tests, and build when available.
10. Update docs if a reusable convention changed.
