# Skill: Accessibility

## Purpose

Target WCAG 2.2 AA unless the project defines another requirement.

## Procedure

1.  Read `docs/accessibility.md`.
2.  Use semantic HTML and landmarks.
3.  Verify heading order.
4.  Verify keyboard access and visible focus.
5.  Give controls accessible names.
6.  Implement correct form labels/errors.
7.  Provide meaningful alt text strategy; hide decorative media.
8.  Verify contrast, reflow/zoom, motion preferences, and modal focus
    behavior.
9.  Run automated checks and perform manual keyboard review.

## Rules

-   Accessibility is part of implementation, not a final cosmetic pass.
