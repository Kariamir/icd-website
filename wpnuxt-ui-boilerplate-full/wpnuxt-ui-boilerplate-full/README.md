# WPNuxt UI Boilerplate — Agent Documentation Pack

Reusable architecture and AI-agent instructions for Nuxt frontends backed by WordPress through WPNuxt.

Start with `CLAUDE.md`, then `docs/README.md`.

This pack intentionally defines architecture and implementation rules rather than forcing one visual framework. Tailwind, plain CSS, or another styling layer can be selected per organization/project, but the CMS boundary, component layers, content contracts, quality gates, and documentation discipline stay stable.
