# Accessibility

Target WCAG 2.2 AA unless a project requires a stricter standard.

## Required checks
- One meaningful `h1` for the main page topic.
- Logical heading hierarchy.
- Semantic header/nav/main/footer landmarks.
- All interactive controls reachable and operable by keyboard.
- Visible focus state.
- Buttons for actions; links for navigation.
- Form controls have programmatic labels and useful errors.
- Meaningful images have useful alt text; decorative images use empty alt/appropriate presentation semantics.
- Modal/dialog behavior manages focus correctly.
- Motion respects reduced-motion preferences where applicable.
- Text and interactive-state contrast meets the target standard.

Accessibility is part of component design, not a final patch.
